# Runtime data review

Every original data/content/locale file is classified below. Included files are byte-preserved. Imported factual fields and prose are not assumed to have identical rights. Populated external software catalogs are withheld whole, without stripping fields. Factual historical music metadata describes slots, not permission for recordings. Original project content is identified by project-specific mechanics, fictional dialogue, schemas and original in-game software definitions; no external prose marker was found in included files. This is local-evidence review, not an independent authorship certification.

Public technical source URLs are references, not private URLs or redistribution grants. No private filesystem paths or artifact links were found in selected data. No exact-copy comparison against external sites was performed.

The 68 bbsarchive localization entries make the translation files mixed-provenance; all locale files are withheld. This prevents a claim of complete localization/buildability.
