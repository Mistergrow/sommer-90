# Sommer '90

- [Playable game](https://misterfloppy.itch.io/sommer-90)
- [DONE WITH AI experiment — DWAI-001](https://github.com/Mistergrow/done-with-ai/blob/main/projects/DWAI-001.md)

Sommer '90 is a retro-computing narrative/management game set in the 1990s.
It predates the formal DONE WITH AI framework; its AI-assisted development
helped motivate the experiment and its designation as DWAI-001.

## Source snapshot

This repository contains a publication snapshot of the release-correlated
Sommer '90 source. The source was correlated with local release manifests/builds.
Some runtime assets are intentionally excluded because their redistribution
rights are separate from the game's source-code license. Software artwork/scans,
Topaz fonts, other artwork and unreviewed audio are excluded. Some external
catalog prose, archive content and mixed-provenance translations are withheld.

This is not a verified complete buildable distribution. Direct preloads refer
to excluded assets; no source was changed to compensate for those omissions.
The released playable game is available at the link above.

See `RUNTIME_DATA_REVIEW.md`, `ASSET_PUBLICATION_REPORT.md`, and
`DEPENDENCY_REPORT.md` for included content, exclusions and missing dependencies.

## Engine

The project declares Godot 4.7 and the verified release package records Godot 4.7.2.
